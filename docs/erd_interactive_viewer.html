🩸 1:1 Unit Traceability

Every successful DONATION_RECORDS yields exactly one barcode-tracked BLOOD_INVENTORY unit via a 1:1 foreign key constraint.

⚡ FEFO Allocation Logic

BLOOD_DISPATCHES links a specific unit to a BLOOD_REQUESTS order based on First-Expired-First-Out expiration dates.

🔒 3NF Normalization

All tables are in 3NF and BCNF. Zero transitive dependencies; all keys generated via Oracle identity sequences.

🍃 Polyglot Persistence

Unstructured reviews, ratings, guidelines, and emergency alerts are persisted in MongoDB with foreign reference keys to Oracle IDs.
